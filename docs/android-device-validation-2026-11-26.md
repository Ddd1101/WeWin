# Android 真机功能验证与修复（2026-11-26）

使用本机 USB 连接的 P0110 手机（Android 17 / API37）安装当前 HTTPS 调试构建，以指定企业负责人账号验证。账号密码、Token、设备序列号与含账号信息的截图不放入仓库。原生客户端当前覆盖商品管理和个人信息，订单及客户等独立页面仍使用 Web。

## 发现的问题和修复

| 问题 | 修复 |
| --- | --- |
| 新建/编辑页仅有图片与保存按钮，没有可输入表单 | 补全四类商品基本信息、材料字段、童装尺码行及成品组成 |
| 搜索仅过滤当前加载页，较早商品无法可靠找到 | 后端增加企业范围内的货号/名称搜索，先筛选再分页；Android提交搜索参数 |
| 缺少童装筛选、详情和统计字段 | 增加童装入口、DTO、详情及尺码成本/售价编辑 |
| 编辑可能重建默认SKU并删除其他SKU | 传递已有SKU ID，同步默认SKU时保留其他SKU数据 |
| 详情页没有删除入口及失败提示 | 增加二次确认、后端引用保护提示及删除成功返回 |
| 切换筛选期间旧请求可覆盖新结果 | 取消旧请求、按请求代次丢弃过期结果；分页使用已提交关键词 |
| 返回列表可能显示旧数据 | 页面恢复时刷新；分页失败提供重试入口 |
| 选中图片读取失败可被静默忽略，上传在主线程读取全部文件 | IO线程有界暂存与上传，失败报错，提交结束清理临时文件 |
| 错误密码401会触发全局登出导航 | 登录失败保留登录页面和错误提示，业务401仍清除会话 |
| HTTP日志记录登录正文与响应，可能包含凭据 | Debug仅BASIC，Release关闭日志，Authorization脱敏 |
| 童装详情使用串珠的克价/单颗成本单位 | 按商品类型展示单位；童装SKU使用尺码标签 |

加载中的统计使用占位符，避免将未加载状态显示为真实零。表单校验包括必填货号/名称、非负成本/售价/重量、串珠品质等级、组成材料与正整数数量、非重复童装尺码。校验错误置于表单顶部并滚动展示；选择材料提供搜索，避免在较长材料/SKU列表中定位困难。

## 构建与回归

- HTTPS `assembleDebug` 成功，构建后更新安装到真机。
- `lintDebug` 成功，无Error；12条Warning涉及自定义Lint兼容、目标SDK、依赖版本和单色启动图标，未将其描述为零警告。
- Django部署回归14项通过；新增搜索用例验证超过一页的数据与跨企业隔离。
- 原有媒体存储/备份逻辑不变，普通客户端继续使用原API路径；搜索增加可选参数。
- 文档与代码按仓库约定在阿里云分批提交，每批合入docs/log.txt后推送。

## 限制

本次为单一Android17设备和指定账号的功能验证，未覆盖所有Android版本、所有角色、正式签名发布、持续压力及大图片上传边界。原生端未实现的订单/客户独立页面不计为已验证。图片验证采用专用小PNG；N1断线/缓存硬容量已有独立部署验收，本轮不重复中断N1服务。
